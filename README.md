# 🚀 AI-Based 5G Network Traffic Prediction

### Intelligent Network Traffic Classification Using Machine Learning

## 📌 Project Overview

The **AI-Based 5G Network Traffic Prediction** project is a machine learning-based application designed to predict and classify 5G network traffic into three categories: **LOW, MEDIUM, and HIGH**.

The system uses a **Random Forest Classifier** to analyze network traffic input data and generate predictions. A user-friendly web interface developed using Streamlit allows users to enter input values, view prediction results, and understand traffic patterns through graphical visualization.

This project demonstrates how Machine Learning can help in network traffic analysis and intelligent network management.

## 🎯 Project Objectives

- Predict 5G network traffic levels using Machine Learning.
- Classify traffic into LOW, MEDIUM, and HIGH categories.
- Visualize prediction results using graphs.
- Develop an interactive web application using Streamlit.
- Demonstrate the application of AI in modern network management.
