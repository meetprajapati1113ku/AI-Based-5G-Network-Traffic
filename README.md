
# AI Based 5G Network Traffic Prediction

## Project Overview
This project uses Artificial Intelligence and
Machine Learning to predict 5G network traffic.

## Project Objective
To classify 5G network traffic into:
- Low Traffic
- Medium Traffic
- High Traffic

## Technologies Used
- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Random Forest Algorithm
- Google Colab

## Dataset Features
- Connected Users
- Bandwidth (Mbps)
- Signal Strength
- Packet Rate
- Hour

## Algorithm
Random Forest Classifier

## Model Accuracy
93% on the generated synthetic test dataset.

## Project Files
1. AI_Based_5G_Network_Traffic.ipynb
2. 5G_Traffic_Model.pkl
3. 5G_Network_Traffic_Dataset.csv

## Model Output
Predicts Low, Medium, or High network traffic.

## Note
This project uses synthetic sample data
for educational and demonstration purposes.
It is not validated on real 5G network traffic.
